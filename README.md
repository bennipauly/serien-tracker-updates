# Serien-Tracker – Updates

Dieses Repo enthält nur die Update-Informationen für das Firefox-Add-on „Serien-Tracker“:

- `updates.json` – wird von Firefox abgefragt, um neue Versionen zu finden
- **Releases** – die signierten Add-on-Dateien (`.xpi`)

Installieren: die neueste `.xpi` aus den Releases in Firefox öffnen bzw. hineinziehen.
Danach aktualisiert sich das Add-on von selbst.
